# Statstical-Computing-Group-work

BIT 4131: Statistical computing
Assignment Overview
This repository contains my individual BIT 2118 Scientific Computing assignment for Mount Kenya University.

The assignment demonstrates numerical and scientific computing techniques using Python.

Technologies and Libraries
Python
NumPy
SciPy
Matplotlib
Repository Structure
code/ – Python programs for the assigned tasks.
documentation/ – Written assignment documentation.
results/ – Program outputs, screenshots and graphs.
Tasks Covered
The assignment covers:

NumPy Arrays and Numerical Computation
Mathematical Functions and Vectorization
Floating-Point Arithmetic and Numerical Errors
Matrix Algebra and Matrix Operations
Systems of Linear Equations
Gaussian Elimination and LU Decomposition
Iterative Methods for Linear Systems
Eigenvalues and Eigenvectors
Root Finding Methods
Polynomial and Nonlinear Equation Solving
Interpolation
Curve Fitting and Approximation
Numerical Differentiation
Numerical Integration
Ordinary Differential Equations
Numerical Optimization
Random Numbers and Monte Carlo Methods
Installation
Install the required libraries using:

python -m pip install numpy scipy matplotlib
Running the Programs
Navigate to the code folder and run a program using:

python Task_02_numpy_arrays.py
Documentation
The written assignment and supporting results are available in the documentation/ and results/ folders.
